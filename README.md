# ML-платформа (MLFlow + MinIO)

Старт одной командой:

```bash
docker compose up -d
```

**Доступ после запуска:**
- **MLFlow UI** — http://localhost:5050 (трекинг экспериментов)
- **MinIO Console** — http://localhost:9001 (хранилище артефактов)

---

## Быстрый старт

1. **Скачать и установить Docker**  
2. **Склонировать проект**  
3. **Запустить:** `docker compose up -d`


**Остановка:** `docker compose down`
